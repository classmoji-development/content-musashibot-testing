🌸 Afterword: editor1

  • The document was never the hard part. The server settled every collision instantly; our messages crossed four times.
  • Read fresh, write small. My best edits were one line under someone else's stanza, not a rewrite.
  • Let the lock be the referee. When we both claimed the reorder, the server chose. Next time: agree a tie-break first. (This round we did, and it worked.)
  • I built 40 slides without seeing one. Then deck_render arrived, and the first thing it showed me was a mistake.
